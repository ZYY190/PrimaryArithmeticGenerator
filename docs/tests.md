## 判断正确性的依据

1. 所有分数运算都先约分，比较时不受相同分数不同写法影响。
2. 每个生成的表达式都会重新解析，解析后的值必须与原表达式值相同。
3. 测试递归检查每个减法节点和除法节点，分别验证非负约束和真分数约束。
4. 测试将全部规范化键放入集合，集合大小必须与题目数量相同。
5. 判分测试使用人工可验证的 `2 × 3 = 6` 和错误答案 `5`，检查正确题号和错误题号是否准确。
